# Darmowe narzędzia

| Do czego                  | Narzędzie                                    | Uwagi                                                                         |
| ------------------------- | -------------------------------------------- | ----------------------------------------------------------------------------- |
| Grafiki i karuzele        | Canva (plan darmowy)                         | szablony z [szablony.md](szablony.md), własna paleta kolorów                  |
| Grafiki precyzyjne        | Figma (plan darmowy)                         | komponenty: chip, karta wzoru, schody                                         |
| Wzory matematyczne        | KaTeX / edytor wzorów w Canvie               | wzór zawsze z lekcji w aplikacji, sprawdzony                                  |
| Planowanie postów         | Meta Business Suite                          | jednoczesna publikacja na FB i IG, planowanie na 10 tygodni                   |
| Krótkie wideo (Reels)     | CapCut (plan darmowy) albo edytor Instagrama | napisy obowiązkowo, wielu ogląda bez dźwięku                                  |
| Nagrania ekranu aplikacji | wbudowane nagrywanie ekranu w telefonie      | tylko przykładowe dane                                                        |
| Statystyki profilu        | Meta Business Suite → Statystyki             | co tydzień: zasięg, zapisania, udostępnienia                                  |
| Statystyki strony         | Cloudflare Web Analytics                     | bez ciasteczek, zgodne z polityką prywatności                                 |
| Linki z kampanii          | parametry UTM w linku                        | np. `?utm_source=instagram&utm_campaign=wzor-dnia`; Cloudflare pokaże ścieżki |
| Pomysły na tematy         | Google Trends, pytania w komentarzach        | sezonowość: kwiecień–maj, sierpień (poprawki)                                 |

Czego nie używamy: kupowanych obserwujących, botów do komentarzy, giveawayów wymagających oznaczania znajomych (łamią regulaminy platform i zasady marki).
